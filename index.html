아이를 위한 성분 안전성 분석

음식·화장품 성분을
사진 한 장으로 안전하게 확인하세요.

휴대폰으로 성분표를 촬영하거나 이미지를 업로드하면, OCR + 성분 DB + 임상/규제 근거를 결합한 LLM이 아기에게 유해한지 신뢰도 높은 분석 리포트를 제공합니다.

* 의료적 진단을 대체하지 않으며, 위험 가능성은 근거 기반으로 투명하게 제공됩니다.

분석 리포트 미리보기

  • 성분 총평: 민감 피부·영아 주의 성분 2건 감지
  • 안전 등급: 주의 (신뢰도 92%)
  • 근거 요약: 국내/해외 안전 가이드 4건 비교
  • 대체 추천: 저자극 대체 성분 3건
근거 출처 공개 리뷰어 검증

핵심 기능

정확한 성분 인식

다국어 OCR과 성분 표준화 엔진으로 스펠링 오류까지 보정해 정확도를 높입니다.

아기 맞춤 위험 분석

영아 피부, 알레르기, 성장 단계별 위험 지표를 분리해 상황별 안내를 제공합니다.

설명 가능한 AI

LLM 답변에 근거 문헌, 안전 가이드, 규제 정보 링크를 함께 제공합니다.

정확도·신뢰도 확보 체계

다층 검증 프로세스

  1. OCR → 성분 정규화 → 위험 규칙 엔진 선분석
  2. LLM이 근거를 요약하되, 근거 미포함 답변은 자동 차단
  3. 고위험 성분은 전문 리뷰어 큐에 자동 등록
  4. 모든 리포트에 신뢰도 점수와 근거 링크 표시

데이터 근거

  • 국내 MFDS/식약처, EU SCCS, EWG, FDA 데이터셋 통합
  • 소아·영아 관련 임상 연구 분류 태그 적용
  • 변경된 규제 업데이트 자동 반영

* 안전성 판단은 공개된 근거와 최신 규제를 기반으로 하며, 불확실성은 명확히 표시합니다.

분석 흐름

1

촬영/업로드

성분표를 촬영하거나 이미지를 업로드합니다.

2

성분 추출 및 정규화

다국어 OCR과 성분 표준화로 오탈자까지 교정합니다.

3

규칙 + LLM 결합 분석

규칙 기반 필터링 후 LLM이 근거 기반 설명을 생성합니다.

4

리포트 제공

안전 등급, 근거, 대체 옵션을 명확하게 제공합니다.

구루들이 추천하는 깔끔한 코드 구조

모노레포 + 책임 분리

프론트, API, 데이터 파이프라인을 분리하고, 공통 모듈은 shared 패키지로 재사용합니다.

apps/
  web/            # 사용자 웹/모바일 UI
  api/            # 분석 API (FastAPI/Node)
packages/
  ocr/            # OCR 파이프라인
  risk-engine/    # 규칙 기반 위험 평가
  llm-core/       # LLM 프롬프트/가드레일
  ui/             # 디자인 시스템
infra/
  docker/         # 배포용 컨테이너
  terraform/      # 인프라 코드

품질·안전성 체크리스트

  • PR 템플릿 + 리뷰 가이드로 위험 변경 점검
  • LLM 응답 검증 테스트 + 회귀 테스트 자동화
  • 데이터셋 버전 관리와 감사 로그 저장
  • PII 마스킹 및 안전한 저장 정책

아기의 안전을 최우선으로.

근거 기반 성분 분석으로 신뢰할 수 있는 결정을 돕는 서비스로 시작하세요.
